# Каталог героев и правила случайного билда

Снимок: 2026-10-14T06:08:40.921Z; игровые файлы клиента **6779** (2026-10-13T13:33:25). Доступны **41 героев** и **164 основных способностей**, с английскими и русскими названиями и локальными PNG.

## Прямые источники игровых данных

- [Герои из игровых KV3-файлов](https://api.deadlock-api.com/v1/assets/heroes?language=english).
- [Русская локализация героев](https://api.deadlock-api.com/v1/assets/heroes?language=russian).
- [Способности и их изображения](https://api.deadlock-api.com/v1/assets/items?language=english).
- [Русская локализация способностей](https://api.deadlock-api.com/v1/assets/items?language=russian).
- [Версия клиента steam.inf](https://api.deadlock-api.com/v1/assets/steam-info).

Deadlock API — общественный парсер игровых файлов Valve. В приложение включены только герои с player_selectable=true, development_state=release и без disabled/in_development/needs_testing/prerelease_only/assigned_players_only/limited_testing. Отключённые прототипы и ещё не выпущенные Violet и Nurse Harrow исключены; полный список исключений и исходные флаги сохранён в assets/heroes.json. Слот способности берётся из hero.items.signature1…signature4, а не из порядка произвольного массива API.

## Проверенные правила

- **12 универсальных слотов**: 9 базовых и 3 открываемых, по одному за каждого вражеского Walker. [Официальное обновление Valve от 21 ноября 2025](https://forums.playdeadlock.com/threads/11-21-2025-update.90383/) установило эти количества и добавило уровни для покупки всех улучшений.
- Четыре способности, у каждой три улучшения со стоимостью **1, 2, 5 AP**, всего **32 AP**. Порядок каждой способности должен оставаться T1 → T2 → T3.
- hero.level_info актуального клиента содержит **36 уровней**: четыре открытия и **32 выдачи AP**. Внутренние required_gold пороги открытия: **0, 500, 1400, 3200**, уровни **1, 3, 5, 8**. Это raw значения API; они отражают заработанные души и могут отличаться от старых таблиц, считающих стартовые 600 душ.
- Первые три открытия расходуются на обычные способности 1–3, в случайном порядке; **ультимейт 4 открывается четвёртым**, на уровне 8. План улучшений — последовательность расходования AP после открытия соответствующего навыка: при необходимости сначала нужно накопить очки или дождаться открытия.

## Обновление

```powershell
node scripts/sync-heroes.mjs
```

--inspect показывает живые флаги и структуру без записи каталога, --refresh-icons повторно загружает PNG. Скрипт проверяет четыре способности и три улучшения для каждого героя, единые 32 AP и четыре открытия. При неполной структуре или недоступных изображениях существующий каталог сохраняется. Во время обычного запуска приложения интернет не требуется.
