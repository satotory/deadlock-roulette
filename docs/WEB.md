# Browser edition / Браузерная версия

[English](#english) · [Русский](#русский)

## English

Open [Deadlock Roulette in the browser](https://satotory.github.io/deadlock-roulette/). The root URL opens the same interface used by the Windows app. No executable or account is needed.

The roulette, hero builds, events, skill plans, sound controls and build archive use browser APIs. Posters and the contract gazette download as PNG files. Music may start after the first click, according to the browser’s autoplay rules.

The browser keeps its own session in local storage, separate from the Windows app. Use **Save / Load** to transfer a JSON session between them. Clearing this site’s data clears the browser’s saved session; keep an exported JSON if you want a backup. Loading the page initially needs an internet connection.

### Build and publish

```sh
node scripts/build-web.mjs
```

The generated `web-dist/` contains only renderer code, media and `version.json`. Local profiles, caches, desktop binaries, raw metadata and credentials are excluded. `web-dist/` is regenerated by the command.

The Pages workflow checks the app, builds this directory and publishes it using GitHub’s built-in deployment token. Enable **GitHub Actions** as the repository’s Pages source once. No personal token belongs in the workflow. [GitHub’s Pages workflow documentation](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages) covers this setup; Pages supports public repositories on GitHub Free.

## Русский

Открой [Deadlock Roulette в браузере](https://satotory.github.io/deadlock-roulette/). По корневой ссылке открывается тот же интерфейс, что и в Windows-приложении. Скачивать `.exe` или заводить аккаунт не нужно.

Рулетка, билдер героев, события, прокачка, настройки звука и архив работают через браузерные API. Постер и газета скачиваются в PNG. Музыка может включиться после первого клика — таковы правила автовоспроизведения браузера.

У сайта своя сессия в локальном хранилище, отдельно от Windows-приложения. Кнопки **«Сохранить / Загрузить»** переносят JSON между версиями. Очистка данных сайта удаляет браузерную сессию; для резервной копии сохрани JSON. Первоначальная загрузка страницы требует подключения к интернету.

### Сборка и публикация

```sh
node scripts/build-web.mjs
```

В `web-dist/` попадают только интерфейс, медиафайлы и `version.json`. Локальные профили, кэши, Windows-бинарники, сырые метаданные и ключи доступа исключены. При сборке папка `web-dist/` создаётся заново.

Workflow Pages проверяет приложение, собирает эту папку и публикует её встроенным токеном GitHub. Один раз выбери **GitHub Actions** источником Pages в настройках репозитория. Личные токены в workflow не нужны. [Официальная инструкция GitHub](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages) описывает публикацию; публичные репозитории поддерживаются бесплатным GitHub Free.
