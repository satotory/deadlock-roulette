## Прямые источники

- [Документация Deadlock API](https://api.deadlock-api.com/docs).

Deadlock API — общественный проект, который разбирает игровые файлы Valve. Он не является сервисом Valve. Названия, категории, тиры, цены и иконки здесь взяты из его прямого ответа, а не собраны по памяти.

## Правила включения

Берутся только записи type=upgrade, shopable=true, disabled не равен true, item_slot_type равен weapon/vitality/spirit, тир 1–5 и положительная числовая цена. Способности героев, оружие героев, удалённые и недоступные shopable=false предметы исключены. Всего исходный ответ содержит 764 определений; после фильтрации осталось 173.

T5 входят в игровые определения как Legendary и относятся к Street Brawl. Это дополнительные записи сверх стандартного магазина T1–T4. Цена 9999 у T5 — техническое значение из API, а не обещание доступности в обычном магазине. Статус режима также подтверждается обсуждениями на форуме игры: [Infinite Rounds в Street Brawl](https://forums.playdeadlock.com/threads/lost-my-legendary-item-due-to-bug-57684618.107744/).

В API corrupted_info хранит усиленные эффекты обычного предмета, а не самостоятельный идентификатор покупки. Поэтому искажённые версии не дублируют T3/T4 в пуле; у исходных предметов сохранён флаг corruptible.

Поле cost — полная стоимость предмета со всеми компонентами. Поле baseCost — цена самого улучшения из исходной записи. Например, Capacitor: 6400 + Tesla Bullets 3200 = 9600.

Иконки PNG загружены из shop_image (при отсутствии — image) в assets/icons и доступны без интернета. Описания очищены от HTML и встроенных SVG. Все IDs в JSON представлены строками для безопасного сравнения и сохранения состояния.

## Обновление

Из корня проекта:

```powershell
node scripts/sync-items.mjs
```

Нужен интернет. По умолчанию существующие корректные PNG используются повторно. Для повторной загрузки всех иконок добавьте --refresh-icons. --inspect выводит сводку из живого API без изменения файлов. При ошибке загрузки или некорректном каталоге существующий JSON сохраняется. Обновление не выполняется при каждом запуске приложения: поставляемый снимок работает полностью автономно.

## Данные для интерфейса

Скрипт одним запуском создаёт assets/items.json и src/catalog-data.js с одинаковым объектом каталога. Интерфейс импортирует ESM-модуль, чтобы запуск через file: не зависел от fetch локального JSON. Не редактируйте сгенерированный модуль вручную; обновляйте данные этой командой.
