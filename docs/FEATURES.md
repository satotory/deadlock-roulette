# Подробное руководство Deadlock Roulette

[Вернуться к странице проекта](../README.md).

Рулетка предметов Deadlock для Windows 10/11 x64. Работает без интернета, установки и прав администратора.

## Запуск

Открой **`dist/Deadlock Roulette.exe`**. Его можно скопировать в удобную папку и запускать двойным кликом. Все иконки, каталог и необходимая среда уже находятся внутри `.exe`.

Состояние сессии автоматически сохраняется в `%APPDATA%\Deadlock Roulette`. Кнопка **«Новая сессия»** очищает только историю выпадений; выбранные категории, тиры, веса и исключения сохраняются.

## Рулетка

- Категории: **Ган / ХП / Спирит**.
- **156 обычных предметов T1–T4**: 53 / 54 / 49 по категориям.
- **17 Legendary** для Street Brawl: отдельный тир `LEG`, выключен при первом запуске.
- Стартовые веса: **T1 = 4, T2 = 3, T3 = 2, T4 = 1**. При одинаковых остальных настройках конкретный предмет T1 имеет в четыре раза больший шанс, чем конкретный T4.
- Итоговый вес предмета = вес тира × вес категории × множитель предмета. Шанс = его вес / сумма весов доступных предметов. Число предметов в тире влияет на общий шанс тира.
- Значения весов **0–100**, в том числе дробные. Нулевой вес исключает предметы из розыгрыша. Тиры и категории также можно выключить кнопкой.
- Размер каждого сектора колеса соответствует вероятности. При большом количестве предметов названия не помещаются на секторах; весь список и индивидуальные шансы доступны в каталоге.
- Выпавший предмет больше не выпадет до новой сессии, даже после смены фильтров, весов и перезапуска приложения. Выбор сохраняется до анимации.

**Пробел** — вращать колесо. **Ctrl K** — поиск. **F11** — полный экран. **Escape** — закрыть диалог или выйти из полного экрана.

Кнопка `♪` включает и выключает фоновую музыку. В настройках звука доступны шесть оригинальных треков: нынешнее меню Title, Hideout, Street Brawl, поиск матча, после матча и классическое меню. Выбор трека сохраняется; переход между треками плавный. Всё входит в `.exe` и работает без интернета. Отдельная кнопка динамика включает щелчки колеса и звук результата. Кнопка `↯` включает быстрый режим.

Кнопка **RU / EN** меняет язык всего интерфейса, включая названия и описания предметов, подсказки и диалоги. Выбранный язык и оба переключателя звука сохраняются после закрытия.

Кнопка с ползунками рядом со звуковыми переключателями открывает **четыре независимые громкости**: музыки, розыгрышей, интерфейса и фраз героев. Значения сохраняются, в том числе 0%. Выключение звука не сбрасывает выбранную громкость. Звуки интерфейса и голоса можно отключить отдельно в этой же панели.

В этой панели можно выбрать **звук прокрутки**: Street Brawl с оригинальным выстрелом выпадения и слоем категории предмета, мягкое дерево, револьвер, кристалл, аркаду или прежнюю механику. **«Прослушать»** проигрывает пример при текущей громкости розыгрыша, даже если щелчки выключены; выбранный стиль и выключатель при этом не меняются.

При выпадении героя звучит его оригинальная короткая реплика из Deadlock. Локальные файлы есть для всех **41 героя**, интернет не нужен. Для фраз доступны отдельные громкость и выключатель; новый выбор героя останавливает предыдущую реплику.

У кнопок, переключателей и отметок прокачки есть мягкие звуковые акценты и световые отклики. При полном инвентаре появляется печать готового контракта. Звуки интерфейса синтезируются локально; выстрел Street Brawl и голоса героев — оригинальные игровые записи. Уменьшение анимации в настройках Windows учитывается.

Щелчок колеса звучит при реальном прохождении границы сектора под указателем. Пропущенные при быстром вращении щелчки не ставятся в очередь, поэтому на замедлении звук не догоняет колесо.

Наведись на сектор остановленного колеса: ячейка увеличится, а карточка покажет иконку, название, категорию, тир и шанс. Кнопка **«Скрыть список предметов»** убирает нижний каталог; выбор сохраняется. **Ctrl K** открывает каталог для поиска.

**Масштаб интерфейса** меняется в верхней панели: кнопками `−` / `+` или выбором процента от **75% до 250%**. Для 2К-монитора можно начать со **150%**. Масштаб сохраняется после перезапуска и при новой сессии.

**Ctrl + / Ctrl −** — увеличить / уменьшить масштаб. **Ctrl 0** — вернуть 100%. **Ctrl + колёсико мыши** также меняет масштаб. Вместе с текстом увеличиваются кнопки, колесо, иконки и диалоги.

Нажми предмет в каталоге, чтобы прочитать описание, изменить личный множитель или исключить его. Поиск понимает русские и английские названия. Кнопки **«Сохранить» / «Загрузить»** экспортируют и импортируют полную сессию в JSON.

Под основной кнопкой рулетки находятся три действия. **«Реролл»** показывает новый результат без расходования предмета и без записи в историю; он остаётся доступен в пуле. **«Апгрейд» / «Даунгрейд»** разыгрывают предмет ровно на один тир выше / ниже показанного и записывают его в историю, как обычное вращение. Они учитывают категории, выключенные тиры, веса и уже выпавшие предметы; кнопка недоступна, если нужный тир выключен, закончился или находится за пределами каталога. Результат предпросмотра тоже сохраняется после закрытия.

У каждого из трёх действий **один заряд на сессию**. Один выпавший предмет можно изменить только одной опцией, а потраченная опция остаётся выключенной для всех следующих предметов. Состояние зарядов сохраняется после перезапуска и входит в JSON. Сброс сессии восстанавливает заряды.

## Билд на персонажа

Вкладка **«Билд на персонажа»** собирает контракт для одного матча:

1. Открой **«Участники розыгрыша»**, выбери подходящих героев и нажми **«Выбрать героя»**. Герои движутся в ленте из трёх постеров: видны предыдущий, текущий и следующий варианты. Каждый включённый герой имеет одинаковый шанс. При остановке выбранный постер раскрывается; порядок открытия умений расположен поверх его нижней части. Цвет страницы плавно меняется на цвет героя.
2. Нажимай **«Разыграть предмет»** под инвентарём или **Пробел**. Предметы движутся в такой же ленте над слотами. Обычный розыгрыш длится около семи секунд, с медленными последними шагами, отдачей и упругой остановкой. Щелчки совпадают с прохождением карточек. Быстрый режим сокращает анимацию примерно до двух секунд. Предметы заполняют **12 квадратных слотов** по столбцам: 1–2, 3–4 и далее; 9 основных и 3 Flex, которые в игре открываются после уничтожения вражеских Walker. В этом билде предметы не повторяются. Веса и фильтры доступны в сворачиваемой панели правил предметов.
3. Читай схему прокачки **слева направо**: четыре строки соответствуют умениям, столбцы — шагам 1–12. Нажимай ромбы, чтобы отметить купленные улучшения; следующий шаг подсвечивается. Первые три умения открываются в случайном порядке, ультимейт — четвёртым. Первое улучшение относится к первому открытому умению. Ранги одного умения идут последовательно и стоят **1 / 2 / 5 AP**, полный план расходует **32 AP**. Дождись открытия указанного умения и накопи нужное число AP для следующего шага.

Кнопка **«Перемешать прокачку»** создаёт новый план для выбранного героя. **«Новый билд»** очищает героя, предметы и отметки прокачки; участие героев сохраняется. У режимов отдельные истории предметов, а веса тиров, категорий и отдельных предметов используются в обоих режимах. Весь билд сохраняется после закрытия и входит в JSON-экспорт сессии.

Перед новым билдом и перемешиванием прокачки появляется подтверждение с отменой по умолчанию. После выпадения героя четыре умения открываются по очереди с четырьмя импульсами. Системное уменьшение анимации отключает ожидание.

Тиры билда включаются и выключаются кнопками в самом низу страницы независимо от обычной рулетки. **Динамические веса** включены по умолчанию: каждый предмет тира умножает вес остальных предметов этого тира на **0,2**. После трёх предметов вес остаётся **0,008 от исходного**. Панель показывает количество предметов, множитель и текущий шанс каждого тира. Если доступен только один тир, он остаётся единственным возможным результатом; уменьшение веса меняет относительные шансы. Переключатель отключает подавление и возвращает настроенные базовые веса.

**«Отменить предмет»** отменяет последний розыгрыш целиком и восстанавливает состав и порядок покупок до него. Проклятый розыгрыш отменить нельзя. Герой, прокачка и архив сохраняются.

Рулетка сохраняет зелёную палитру, а фон билда плавно меняется под выбранного героя. Для всех 41 героя сохранены оригинальные загрузочные фоны и полные игровые рендеры; исходники и происхождение указаны в `assets/hero-art/source.json`.

**Архив контрактов** позволяет дать билду имя, поставить до пяти звёзд, написать комментарий и сохранить героя, предметы и план прокачки. Можно сохранить до 30 контрактов, в том числе ещё не заполненные билды. Повторный клик по выбранной звезде убирает оценку; комментарий вмещает до 1000 символов. Загрузи контракт для следующего матча: отметки прокачки сбросятся, а состав билда восстановится. Архив, оценки и комментарии сохраняются после перезапуска и входят в JSON-экспорт; обычная рулетка и выбранные участники розыгрыша остаются твоими текущими.

У сохранённого контракта есть **«Посмотреть»**: герой, предметы, открытие умений и подробная прокачка доступны в отдельном окне без загрузки в текущий билд. Кнопка **«Оценить»** меняет звёзды и комментарий после матча у того же контракта, сохраняя его идентификатор, дату и содержимое. Новая копия при этом не создаётся.

Каталог героев: **41 выпущенный игровой герой**, 164 способности с локальными иконками и EN/RU названиями. Правила и источники: [docs/hero-sources.md](hero-sources.md). Обновление героев: `node scripts/sync-heroes.mjs`, затем `npm.cmd run build`.

## Ритуалы, сделки и история — 1.9

**Курица** теперь смакует бросок: около 8 секунд в обычном режиме и 4,6 секунды в быстром. После остановки D12 результат остаётся на экране до нажатия **«Продолжить»**. Бросок уже сохранён; перезапуск возвращает тот же результат с кнопкой подтверждения. Из каждой выклёванной иконки вылетают перья. История происшествий сохраняет число на кубике и потерянные предметы; на всех вещах перерозыгрыша после 12 стоит значок курицы.

**Архимать** предлагает дар через три независимых вертикальных барабана. Они останавливаются по очереди, после чего можно выбрать один предмет. Он сразу попадает в инвентарь, без второй рулетки. На даре, в маршруте закупа и в архиве остаётся сапфировая метка Архиматери; выбранный предмет также записывается в историю событий.

**Тайный король** приходит только после получения минимум пяти предметов и предлагает одну из четырёх сделок:

- **Королевский обмен:** отдать одну доступную непроклятую вещь за запечатанный предмет другого тира или связку.
- **Самозванец:** следующие три закупки — две настоящие королевские вещи T3/T4 и одна подделка T1. Содержимое и расположение подделки скрыты до ручного раскрытия; результаты фиксируются при выборе сделки.
- **Тайная казна:** заменить три последних полученных предмета на запечатанные T4 и связку из двух новых вещей.
- **Королевский указ:** до конца билда усилить веса спирита или живучести в шесть раз либо запретить T1. Указ разыгрывается из доступных для текущего пула.

Все сделки учитывают фильтры, веса, совместимость героя, рецепты и ёмкость инвентаря. Невозможный вариант отмечается с причиной. Королевские награды отмечены короной; печати открываются по одной через маршрут закупа. Выбор сделки, дары и история сохраняются после перезапуска. Старые сохранения с режимом скрытия всех покупок остаются совместимыми.

В настройках шансов нажми название или значок события, чтобы открыть описание правил. Сработавшие события отмечены цветной печатью. Игровые цвета и символы покровителей взяты из локальных ресурсов Valve: [источники](fate-presentation-sources.md). Громкость новых звуков общая со звуками колеса.

Иконки открытия умений под героем увеличены, высота его карточки не растёт вместе с длинным закупом. По её краям постоянно движется мягкий свет в цвет героя. **Постер матча** расширен до 2600 пикселей: персонажу отведена большая часть изображения, окно просмотра также стало шире.

## Городские происшествия и газета — история версии 1.8

Внизу билдера появились три отдельные настройки шанса: **Курица, Архимать и Тайный король**. По умолчанию у каждого 10% на обычный розыгрыш; 0% отключает событие. Каждое появляется **только один раз за текущий билд**. Отмена и перезапуск не возвращают события; новый билд или сброс предметов начинают новую сессию. Реролл, апгрейд и даунгрейд сами эти события не запускают.

- **Курица судьбы** может прийти, когда в инвентаре уже минимум три предмета. Она бросает D12 и выклёвывает последние полученные предметы, независимо от перестановки T1: 1–6 — один, 7–9 — два, 10–11 — три. На 12 весь инвентарь очищается и заново разыгрывается под проклятием: все предметы заперты, отмена и правки недоступны. Фильтры, заряды героя и рецепты учитываются; слишком узкий пул заполняет столько слотов, сколько возможно. Исход сохраняется до эффекта, поэтому закрытие приложения не переигрывает кубик.
- **Архимать** предлагает три случайных одиночных предмета без повторов: выбираешь один, два остальных остаются в пуле. Предложение сохраняется до выбора; закрытие приложения возвращает те же три варианта. Обычное проклятие может сработать после выбранного дара.
- **Тайный король в старых сохранениях 1.8** запечатывает все последующие покупки. В новых билдах версии 1.9 вместо этого доступны четыре сделки, описанные выше. Их названия, иконки и тиры скрыты в барабане, инвентаре, маршруте, архиве, постере и газете. Кнопка **«Открыть следующую покупку»** раскрывает только ближайший закрытый шаг маршрута; используй её, когда дойдёшь до этого закупа в матче. Раскрытые шаги сохраняются. Чтобы косвенно не выдать тиры, шансы пула скрываются до раскрытия всех покупок.

**«Городская газета»** превращает текущий или сохранённый контракт в отдельный выпуск: портрет героя, ироничный заголовок, редакционные слухи, предметы, полный маршрут закупок и твой послематчевый отзыв. Содержание берётся из билда; газетные шутки не выдают себя за реальные результаты матча. Газету можно сохранить в PNG. Запечатанные покупки остаются тайными и на картинке.

У новых событий есть собственные анимации и звуки. Их громкость и выключатель общие со звуками колеса; музыка, фразы героев и звуки интерфейса управляются отдельно.

## Порядок покупок — 1.7

Под инвентарём находится отдельный пошаговый маршрут покупок. Он сохраняет базовый предмет после объединения с улучшением: например, Mystic Vulnerability остаётся ранним шагом, а Escalating Exposure появляется позже. Поздние T1 переносятся в раннюю часть маршрута. Отмена восстанавливает маршрут вместе с инвентарём; после реролла ненужные шаги заменённой ветки исчезают. План входит в сохранённые контракты и экспорт сессии, виден в предпросмотре.

Барабан предметов стал ниже. Замок проклятого предмета расположен прямо на верхнем углу его иконки. Появление проклятия длится около 2,8 секунды в обычном режиме и 1,8 секунды в быстром, с отдельной паузой для чтения. При уменьшении анимации остаётся спокойное появление сообщения с такой же паузой.

## Связки, компоненты и проклятия — 1.6

- Улучшенный предмет объединяется со своими компонентами: **Mystic Vulnerability → Escalating Exposure** и ещё 61 проверенный рецепт. Компоненты освобождают место; имеющееся улучшение не дублируется базовым предметом. Старые билды также очищаются от таких дублей.
- Поздний **T1** вставляется в случайную позицию **1–5**, остальные покупки сдвигаются. Кнопки правки продолжают работать с последним выпавшим предметом по его билету. В старых сессиях T1 один раз переносятся вперёд, затем порядок сохраняется.
- **20 связок** участвуют в колесе как дополнительные билеты рядом с одиночными предметами. Дабл занимает два обычных слота; уже имеющаяся часть повторно не добавляется. Вес связки равен среднему весу её компонентов × 0,35, оба компонента должны пройти фильтры. Связки можно выключить в особых правилах.
- **Проклятие: 50% по умолчанию, 0–100% в настройках.** У каждого обычного предмета своя проверка, у дабла их две. После срабатывания сразу разыгрывается дополнительный одиночный предмет с замком: его нельзя изменить или отменить. Дополнительные предметы не запускают новую цепочку проклятий. При отсутствии подходящего места проклятие гаснет. Все исходы сохраняются до анимации; закрытие приложения не возвращает проклятый предмет в пул.
- **Extra Charge, Rapid Recharge и Recharging Rush** исключаются для героев, у которых нет способностей с зарядами ни изначально, ни после улучшений. Omnicharge Signet остаётся доступным: он сам добавляет заряды и снимает ограничение, если включены Legendary.
- В прокрутке предметов видны **пять карточек**. При запуске центрируется весь блок героя и инвентаря. Отмена восстанавливает состав до розыгрыша, включая слияния и перестановку покупок; потраченные заряды правок сохраняются.

Рецепты и заряды проверены по игровым свойствам. Связки составлены для этого приложения и описаны в [docs/game-rules-sources.md](game-rules-sources.md). Проклятие использует оригинальный игровой звук Cursed Relic; громкость и выключатель общие со звуками колеса.

В билдере тоже есть **реролл, апгрейд и даунгрейд** с отдельными от обычной рулетки зарядами. Они заменяют последний розыгрыш целиком, даже если его T1 переместился в начало списка; исходные предметы остаются исключёнными до сброса предметов. Отмена восстанавливает веса, но не возвращает потраченный заряд. Настройки тиров вынесены в нижнюю часть страницы.

**«Постер матча»** собирает героя, финальный инвентарь, маршрут покупок, открытия умений и все 12 улучшений в PNG шириной 2600 пикселей. Высота подстраивается под число покупок. Открой предпросмотр и сохрани картинку через стандартное окно Windows. Билд при этом сохраняет свой состав и отметки.

## Актуальность каталога

Каталог проверен 14.10.2026: игровые данные **6779 от 13.10.2026**. Отбираются доступные магазинные предметы из Deadlock API; удалённые и отключённые определения не включены. Цена учитывает необходимые компоненты. Названия доступны на русском и английском, иконки сохранены локально.

Источники и правила отбора: [docs/catalog-sources.md](catalog-sources.md).

## Разработка и сборка

Требуется Node.js. Команды выполняются в папке проекта:

```powershell
npm.cmd install
npm.cmd start
npm.cmd test
npm.cmd run build
```

`npm.cmd run build` создаёт переносимый файл `dist/Deadlock Roulette.exe`. `npm.cmd run build:unpacked` создаёт папку с приложением без упаковки.

Обновить каталог и иконки из интернета, затем пересобрать приложение:

```powershell
npm.cmd run sync-items
npm.cmd run build
```

Для принудительной перезагрузки существующих иконок: `node scripts/sync-items.mjs --refresh-icons`. Скрипт одновременно обновляет `assets/items.json` и `src/catalog-data.js`.

Генератор исходов использует Web Crypto, равномерное 53-битное число без `Math.random` и деления по модулю. Выбор проверяется модульными тестами; тесты сессий проверяют отсутствие повторов и восстановление состояния.
